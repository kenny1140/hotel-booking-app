# 🏨 Hotel XYZ — Boutique Hotel Booking App

A modern, responsive web application for seamless hotel room bookings. Designed with a warm terracotta design system and engineered using vanilla Web technologies with zero external framework dependencies.

## ✨ Features

- 📅 **Dynamic Date & Night Calculations:** Automatically computes total length of stay and validates logical date ranges (check-out must be after check-in, capped at a maximum 30-night stay).
- 🏷️ **Object-Driven Pricing Engine:** Real-time rate calculation based on selected room tier (*Standard*, *Deluxe*, or *Suite*).
- 🌐 **Localized Formatting:** Uses native JavaScript `de-DE` locale formatting for clean date presentation.
- 🎨 **Warm Terracotta UI & Animations:** Custom CSS custom variables system complete with a smooth `slideDown` keyframe animation for instant DOM receipt generation.
- 💾 **Local Data Persistence:** Saves submitted bookings directly to browser `localStorage` as structured JSON arrays, surviving page reloads.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties & Keyframes), Vanilla JavaScript (ES6+)
- **Storage:** Web Storage API (`localStorage`)
- **Version Control:** Git & GitHub
